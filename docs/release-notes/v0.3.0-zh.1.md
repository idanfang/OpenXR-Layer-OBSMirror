# OpenXR OBS Mirror v0.3.0-zh.1（简体中文汉化版）

本版基于上游 `v0.3.0-beta.14`，是**非官方简体中文汉化版**：仅新增中文语言包，
英文原文与英文界面完整保留，任何语言资源缺失都会自动回退英文。

## 本版内容

- **OBS 插件界面中文化** —— 新增 `zh-CN.ini`；裁切预设下拉列表（含"不裁切"）也能显示中文，
  设备名（如 `Reverb G2`）保持原文。
- **控制中心中文化** —— 仪表盘、过扫描、相机平滑、UI 层、安装、诊断各页面，
  以及状态提示、开关文案与确认对话框。
- **安装程序中文化** —— 中文安装向导、中文安装说明页、完成页汉化声明，
  以及桌面快捷方式等自定义消息。
- **中文文档** —— 仓库首页即中文 `README.md`（英文保留在 `README.en.md`），
  另有 `docs/INSTALL.zh-CN.md` 与 `docs/LOCALIZATION.md`。
- 共 312 条界面文案全部有中文，0 条回退英文。

## 语言如何生效

| 位置 | 跟随的设置 |
| --- | --- |
| OBS 插件（源属性面板） | OBS 的语言：设置 → 通用 → 语言 → 简体中文 |
| 控制中心 | Windows 系统语言；也可设环境变量 `OBSMIRROR_LANG=zh-CN` 强制指定 |
| 安装向导 | 安装第一页选择"简体中文"（中文系统会自动选中） |

## 安装

1. 关闭 OBS Studio 和正在运行的 OpenXR 应用。
2. 运行 `OpenXR-OBSMirror-0.3.0-zh.1-Setup.exe`。
3. 打开 OBS，添加 **VR 镜像采集（自动：OpenXR / SteamVR）** 源。

**不需要先卸载英文版**：安装程序沿用上游的安装标识（AppId），会就地升级覆盖，
并保留原有的英文语言文件，方便随时切回英文。若只需要绿色版，可下载 Portable ZIP，
解压后双击 `Launch OpenXR OBS Mirror.cmd`，在控制中心点"安装 / 更新"。
