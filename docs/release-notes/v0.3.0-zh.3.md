# OpenXR OBS Mirror v0.3.0-zh.3（简体中文汉化版 · 一致性修复版）

本版**不改变中文界面与功能**，修的是"汉化有没有把英文那侧弄脏"以及一批工具链问题：
上游自动代码审查（cubic）对本汉化 PR 提了 17 条意见，本版把它们全部修完——
其中 4 条属于**英文用户实际会看到的回归**，是本版最值得升级的理由。

## 一、英文用户会看到的问题（本版修复）

1. **英文界面少了空格**
   预览状态行会显示成 `frame•  CPU fallback`（项目符号紧贴前面的字）。
   根因不在翻译，而在生成脚本：`Import-Csv` 会**吃掉每个字段的首尾空格**，而这两个后缀
   本身就以前导空格开头。已改为手工解析翻译表，并让校验脚本逐条比对 resw 与表格的值。
2. **诊断日志里混进了中文**
   中文模式下，预览诊断日志（`ControlCenter-preview.log`）的部分明细会写成中文。
   本汉化版的设计约定是"界面可翻译，日志与诊断报告保持英文"，便于与上游 issue 对照排查。
   现在日志只写英文原文，界面该显示中文的地方仍显示中文。
3. **"预览已停止"状态的中文提示之前不显示**
   该状态有一条中文资源（`Code_Svc_PreviewStoppedReopenDetail`）从未被代码引用，
   界面一直显示英文。现已接上。
4. **安装程序元数据**
   发布者与公司字段原本会把中文写进"添加/删除程序"与文件属性。
   本版两条路走：**汉化版自己的安装包保留 `Elliott Tate (中文汉化: idanfang)` 署名**
   （这是你要看到的出处），而提交给上游的 PR 分支保持语言中性，避免英文安装出现中文。

## 二、工具链与代码整理

- 新增 `localization/tools/TranslationTable.ps1`：翻译表解析只保留一份实现，
  生成器、校验器、XAML 注入器共用（也正是它修掉了上面第 1 条）。
- 校验脚本（`Test-Localization.ps1`）新增：resw **逐值**与表格比对、resw 陈旧条目、
  未被任何 C# 引用的 code 资源、OBS 语言文件重复键、缺 `en-US.ini` 不再静默跳过、
  跨行的 `Loc.S/F` 调用也会被检查。
- 生成器的重复资源名检测改按归一化名分组（`Text#2` 与 `Text` 不会再互相覆盖）。
- `Add-XamlUids.ps1 -Reset` 不再吞掉失败（此前会以退出码 0 假装成功）。
- 三个脚本改为在正文里解析默认路径：带 `[CmdletBinding()]` 时 Windows PowerShell 5.1
  会在 `$PSScriptRoot` 赋值前求值参数默认值，导致文档里的 `-File` 调用方式一直跑不起来。
- 删除两处无调用者的死代码（`Loc.DescribeResourceResolution()`、
  `MirrorPreviewService.DiagnosticWaiting()`）；`Loc.Cache` 改用 `ConcurrentDictionary`
  （界面线程与预览后台线程会并发读写）。
- OBS 插件：以 `@` 开头的裁切预设名在没有对应译文时保持原样，不会把用户自建的
  设备名静默改写。
- `THIRD_PARTY` / `docs/NOTICE-ZH-CN.md`：GPL 声明措辞改为准确表述
  （插件源码在本仓库，但编译需要 OBS Studio 源码树提供头文件与 libobs）。

## 三、验证

- `ControlCenter` 用 .NET SDK 编译通过（0 error）。
- Inno Setup 6.7.3 编译通过（0 错误）；删除中文语言文件后仍可编译（此时仅英文界面）；
  编译产物的版本信息 `CompanyName` 精确等于 `Elliott Tate (中文汉化: idanfang)`。
- `localization/tools/Test-Localization.ps1` 全绿；在修复前它能复现上述第 1 条的空格漂移
  与第 3 条的未引用资源，说明新检查确实有效。
- OBS 插件由本仓库的云端构建（GitHub Actions，windows-2022）编译，与本版安装包同源。

## 四、安装

1. 关闭 OBS Studio 与正在运行的 OpenXR 应用。
2. 运行 `OpenXR-OBSMirror-0.3.0-zh.3-Setup.exe`：沿用同一安装标识（AppId），
   会**就地覆盖** zh.1 / zh.2，无需先卸载。
3. 打开 OBS，添加 **VR 镜像采集（自动：OpenXR / SteamVR）** 源。

偏好便携版：解压 ZIP，双击 `Launch OpenXR OBS Mirror.cmd`，在控制中心里用 **安装 / 更新**。

其余说明见 `docs/INSTALL.zh-CN.md`；本汉化版的声明与已知限制见
`docs/NOTICE-ZH-CN.md` 与 `docs/LOCALIZATION.md`。
